# NEXORA

Connect Ideas. Create Impact. A student-driven technology community platform.

## Stack

Next.js (App Router), React, TypeScript, Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Structure

- `src/app` – routes (home, community, learning, projects, events, groups, members, auth, legal)
- `src/components` – shared UI; `src/components/home` – landing page sections
- `src/lib/data.ts` – sample content until the database phase
- `src/assests` – brand assets (logo)
